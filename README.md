# Physics Data Analytics & Computational Modeling

Welcome to my technical portfolio repository. This space showcases how I bridge **Applied Physics** and **Information Technology** using Python to solve data-driven engineering and scientific problems.

## Featured Project: Laser Beam Transverse Profile Analyzer
* **Objective:** Parse, analyze, and map experimental laser intensity variations to determine peak energy thresholds.
* **Core Physics Concepts:** Optics, wave propagation, spatial intensity distributions, Gaussian metrics.
* **Tech Stack:** Python 3, NumPy (matrix arrays), SciPy (Gaussian fitting), Matplotlib (2D contour maps).

## Repository Structure
* `laser_profile_analyzer.py`: A fully functional script executing data synthesis, optimization, and visualization.
